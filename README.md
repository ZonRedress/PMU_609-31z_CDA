<h2>Описание проекта</h2>
Telegram-бот на Python для погоды с испозование aiogram, позволяет пользователям мгновенно узнавать текущую погоду в любом городе мира
Бот принимает на русском языке, и отправляет запрос к  API OpenWeatherMap
